What determines the sound?

The words, explicit tags, selected voice, and speech model all affect the result. Optional previous spoken text provides continuity. Situation notes help the caller choose a cue; this renderer does not analyze them or infer an emotion.

caller-chosen cue + text → renderer → tagged text → ElevenLabs → audio

This page plays recorded files. It asks for no API key and makes no generation requests. To edit text, cues, and voice settings, run the local playground described in the README.
